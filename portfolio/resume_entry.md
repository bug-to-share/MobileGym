# 多模态与后训练实习简历项目经历

## 推荐正文

**基于 Qwen3-VL 的多模态 GUI Agent 在线强化学习**
Qwen3-VL-4B · GRPO · rLLM · verl · vLLM · FSDP · Playwright · TensorBoard

- **多模态后训练：** 基于 MobileGym 扩展截图观察、坐标动作、状态判分与策略更新的在线 RL 流程，在 6 GPU 配置下开展 Qwen3-VL-4B 训练，使用 96/128 个环境槽位收集多步交互轨迹。
- **采样与奖励：** 实现按组内奖励差异筛选的动态补采样及回退机制，协调多轮 rollout 的推理副本生命周期；新增严格结果奖励、错误完成清零分支，开展 6 组主要探索性对照。
- **实验结果：** 在同一组 256 个验证任务上，单次训练严格成功率由 8.98% 提升至最高 21.88%，增加 12.89 个百分点；结合逐任务结果分析跨应用、长链任务及终止行为瓶颈。
- **可靠性与复现：** 完善任务模板重建、环境池分批预热与初始化失败清理；结合 TensorBoard 和原始轨迹复盘采样成本、验证集合变化及浏览器异常对结果的影响。
